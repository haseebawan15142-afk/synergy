# Content Writing

## Style

- Short paragraphs; bullets for specs and feature lists.
- Lead with benefit, then feature/detail.
- Active voice; specific numbers and facts when verified.

## Headlines

- Clear and scannable; avoid vague marketing fluff without substance.
- Match user search intent (product name, service, location if relevant).

## Product & Spec Copy

- Use manufacturer-accurate specs; note “specs subject to change” if business requires.
- Call out warranty, compatibility, and what’s included in the box when selling hardware.

## CTAs

- One primary CTA per section; consistent wording across the site for the same action.

## Localization

- Default language per business; consistent spelling and units unless multi-locale is in scope.

## Maintenance

- Date-sensitive offers include validity; remove expired promotions promptly.
